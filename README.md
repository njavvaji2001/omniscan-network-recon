# 📱 OmniScan: Multi-Threaded Network Reconnaissance & Asset Inventory Tool

An asynchronous, cross-platform local network asset discovery utility designed to automate device tracking and port fingerprinting. Built entirely with Python and the KivyMD framework, this application provides administrators with a zero-configuration dashboard to audit local subnets and identify rogue connected nodes without requiring router firmware authentication.

## 🚀 Single-Line Command Terminal Setup & Execution

To download the system, configure dependencies automatically from the requirements package map, and launch the dashboard, copy and paste this command block directly into your terminal workspace:

```bash
git clone https://github.com && cd omniscan-network-recon && python3 -m venv env && source env/bin/activate && pip install --upgrade pip setuptools wheel && pip install -r requirements.txt && python3 main.py
```

### Manual Individual Phase Instructions
If you prefer configuring individual stages manually, follow these terminal instructions:

1. **Clone and Enter Workspace:**
   ```bash
   git clone https://github.com
   cd omniscan-network-recon
   ```
2. **Build and Activate Environment Container:**
   ```bash
   python3 -m venv env
   source env/bin/activate
   ```
3. **Automated Requirements Installation Package Execution:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Launch Application Screen Utility:**
   ```bash
   python3 main.py
   ```
